Adaptive Frame Skipping & Motion Gating

Border perimeters are static 80% of the night. Why run 60-millisecond deep neural networks when not a single pixel moves?

How It Works

1. Downsamples incoming 1080p frame to 320x240 grayscale.
2. Computes absolute difference against background accumulator.
3. Calculates motion fraction against 0.5% threshold.
4. If static: Bypasses deep inference, maintains tracker velocity, emits live telemetry in <2.8ms.
5. Heartbeat safeguard: Forces full inference every 15 frames to guarantee no slow crawls escape.
