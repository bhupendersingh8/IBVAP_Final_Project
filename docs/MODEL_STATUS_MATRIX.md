## 1. Compliance Policy & Status Definitions

In accordance with strict operational integrity guidelines:
- **No untested models promoted**: A model is designated `PRIMARY` only after passing:
  $$\text{INSTALL} \longrightarrow \text{LOAD} \longrightarrow \text{REAL INFERENCE} \longrightarrow \text{IBVAP ADAPTER} \longrightarrow \text{INTEGRATION TEST} \longrightarrow \text{REGRESSION TEST}$$
- **Honest hardware distinction**: If a model has not been run on physical NVIDIA silicon, GPU benchmarks are recorded as `PROFILE_READY (TensorRT FP16 Target)` and not claimed as physically verified on the host Dell.
