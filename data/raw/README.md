# Raw Test Video Data

This directory stores raw `.mp4` files for local end-to-end testing (e.g., simulating CCTV feeds via FFmpeg and MediaMTX).

**Rules:**
1. Do NOT commit any `.mp4` files to Git. The `.gitignore` is configured to exclude them.
2. Only place authorized or openly licensed (e.g., CC0, CC-BY) footage here.
3. Keep track of the provenance and license of every video you place here. Do not scrape copyrighted feeds (e.g. YouTube/EarthCam).
